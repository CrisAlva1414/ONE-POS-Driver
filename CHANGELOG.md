# 📝 Changelog

Todos los cambios importantes de este proyecto serán documentados aquí.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-es/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [2.0.0] - 2024-10-17

### ✨ Agregado
- **Mega tutorial completo** en README.md con guías paso a paso
- **Documentación estructurada** en carpeta `docs/`
- **Guía de inicio rápido** para configuración en 5 minutos
- **Guía de desarrollo** con ejemplos de código para múltiples lenguajes
- **Solución de problemas** con diagnósticos detallados
- **Guía de contribución** para colaboradores
- **Soporte multiidioma** en documentación
- **Ejemplos prácticos** para cada tipo de conexión
- **Tabla de compatibilidad** por sistema operativo

### 🔄 Cambiado
- **Reestructuración completa** de la documentación
- **Formato mejorado** para mejor legibilidad
- **Organización** de contenido por nivel de usuario (básico/avanzado)
- **Unificación** de toda la información dispersa en PDFs

### 🗑️ Eliminado
- **Archivos PDF** duplicados y pesados
- **Documentación** redundante y desactualizada
- **Archivos temporales** innecesarios

### 🛠️ Mejorado
- **Navegación** más intuitiva
- **Búsqueda** de información más rápida
- **Accesibilidad** para usuarios no técnicos
- **Mantenimiento** de la documentación

## [1.0.0] - 2024-XX-XX

### ✨ Versión Inicial

- SDKs para Android, iOS y Windows
- Herramientas de prueba y configuración
- Documentación básica en PDFs
- Soporte para múltiples tipos de conexión
